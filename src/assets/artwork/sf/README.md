# San Francisco skyline backgrounds

Original artwork generated with the built-in imagegen tool on October 20, 2026, edited on October 21 to include the Golden Gate Bridge, and revised on October 27 to make the bridge more prominent while keeping the city dominant. The October 27 set was approved after preview. The daytime composition is the reference for the three lighting edits. All four are bundled locally as optimized 1536×1024 WebP images; the interface retains its existing Fluid theme.

The Bay Bridge remains on the left, with the Golden Gate Bridge's larger orange suspension towers and span occupying the right third behind Telegraph Hill. This is a stylized panorama rather than an exact geographic view.

The [Golden Gate revision prompts](GOLDEN_GATE_PROMPTS.md) record the current asset edits.

| Asset | Local clock |
| --- | --- |
| [dawn.webp](dawn.webp) | 05:00–07:59 |
| [day.webp](day.webp) | 08:00–16:59 |
| [sunset.webp](sunset.webp) | 17:00–19:59 |
| [night.webp](night.webp) | 20:00–04:59 |

These are fixed clock periods, not astronomical sunrise/sunset calculations. The background refreshes each minute and when the app regains focus or visibility. Images are decorative and do not change the selected UI theme.
